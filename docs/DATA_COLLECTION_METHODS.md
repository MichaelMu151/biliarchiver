> 词表唯一源：`bili/labor_lexicon.py`（`match_labor()`），与 `css_pipeline/preprocess.py`、
> `bili/analysis_hygiene.py` 保持同源。门禁实现：`bili/academic.py::evaluate_gate`。

| 层 | 内容 | 在采集里的作用 |

## 五路任务与词表的关系

### 1. UP 主归档（archive，4 次）
- 要求：130 个劳工向账号全量归档（视频+评论+弹幕+动态），**不经过词表门禁**（`pass_filter` 全过）。
- 词表用途：事后打标 `labor_tier`，不做剔除。`摩的司机徐师傅`等核心账号的 726 篇转写主力来自这里。

### 2. 学术滚雪球（academic，7 次，最新 e9f81b4b80fd）
- 要求：从种子 UP 的推荐流按 `evaluate_gate` 扩散，门禁顺序：分区黑白名单 → `tag_terms`（19 词）→ **劳工词表** → 家庭排除 → 播放量/互动量。
- 本次 206 通过 / 412 剔除。已知偏差：`tag_terms` 比词表窄，误杀 56 篇（见 `data/exports/recrawl_shortlist.csv`），
  下轮改为先过词表再过 tag_terms（`docs/GPU_MODEL_PLAN.md` 已立项）。

### 3. 关键词采样（keyword，9 次）
- 要求：`tag_terms` 19 词（就业/失业/薪资/找工作/体制内/内卷/大厂/职场/加班/打工人/996/双休/裁员/劳动法/社畜/牛马/工厂/流水线）
  全 B 站搜索，标题至少命中其一才进列表，时间窗共用。
- 词表用途：召回后统一用 `match_labor` 复核定级，`moderate` 单出需人工看。

### 4. 选题预览（scout，1 次 · 130 账号 · 劳工词表筛选）
- 要求：只用词表（不用 tag_terms），快速扫 130 账号的新投稿，命中即入候选。
- 这是词表最纯的一路：无 tag_terms 污染，可当作评价门禁召回率的金标准对照组。

### 5. 按 BV 转写/采集（transcribe/bv，8 次）
- 要求：指定 BV 清单强制转写（`forced_transcribe`，如本次 964 篇），**跳过一切门禁**。
- 词表用途：转写后打标。`recrawl_shortlist.csv` 的 240 条回炉走此通道。
