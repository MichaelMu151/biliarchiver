使用指南

三种采集分开用：按 UP 主、学术滚雪球、按视频号。每种都能从头开始，也能续跑中断的任务。

就绪

三种采集，用途不同

按账号归档、按推荐滚雪球，或只补你点名的视频。

本工具走 B 站公开 Web 接口，带 WBI 签名、buvid3 和风控退避。结构化数据进 SQLite，给人读的内容写成 Markdown。每种采集页都有「从头开始」和「续跑选中任务」：前者新建任务号，后者接着同一个任务和磁盘检查点。

UP按账号归档
雪球沿推荐抽样
BV只采列出的视频
续中断后接着跑

你会得到什么

  • 视频：播放 / 点赞 / 投币 / 收藏 / 转发、简介、分P、评论、弹幕
  • 语音：优先官方/AI 字幕；否则本机 Whisper，或把音频送到你租的云端 GPU
  • 动态：正文、图片、OCR 文字、评论
  • 账号：粉丝、关注、获赞、投稿数的时间序列快照

数据为什么这样存

粉丝和关注每天都在变，不适合只写进一个 Markdown 再覆盖。因此：

  • profile.md 给人看当前画像
  • stats.csv / snapshots.jsonl 追加每次快照，适合画涨粉曲线
  • app.db 便于筛选和断点续跑
  • 每个视频/动态一个文件夹，video.md 里嵌转录和 OCR

操作步骤

  1. 找到 UID 打开 UP 主页，地址形如 https://space.bilibili.com/123456，数字就是 UID。可一次粘贴多行。
  2. 可选登录 匿名也能采元数据。登录后评论更完整（含 IP 属地）、字幕更容易拿到、空间列表也不容易被截短。到「设置与登录」扫码或粘贴 Cookie。
  3. 选时间窗口 全部 / 3 年 / 2 年 / 1 年 / 9 个月 / 6 个月。列表按发布时间倒序，一旦早于窗口就停止翻页。
  4. 选媒体策略 「仅链接」最稳；「音频」适合转写；「完整视频」需要 ffmpeg，体积大。提取文字后可以删除本地媒体，只保留 BV 链接；也可以压缩或上传 Google Drive。
  5. 开始或续跑 新任务点「从头开始」。跑到一半断了，在同一页的下拉框里选那次任务，点「续跑选中任务」；运行监控里也能续跑。不要为了续跑再开一个新任务。

音频、视频和文字提取是三件不同的事

① 只采资料

选择“保留页面链接”。最省空间，不请求会过期的播放直链。

② 获取官方字幕

选择“官方字幕优先”。无需下载音频；有字幕即可直接生成 Markdown、JSON、SRT 和 WebVTT。

③ 本地语音识别

媒体选“下载音频”，转写选“Whisper 兜底”或“全部重新识别”。没有官方字幕也能得到文字。

④ 完整视频归档

媒体选“下载完整视频”。音频和视频流可断点续传，有 ffmpeg 时自动合并 MP4。

⑤ 图片 OCR

开启“动态图片 OCR”。图片会先校正方向和尺寸，再输出正文、置信度和文字坐标。

⑦ Whisper / OCR 算力

完整归档和文字研究可以选本机，或把音频和动态图片送到已激活的云端 GPU 工作机。这不是第四种档案类型。

⑧ 三种采集别混用

按 UP 主：整库归档指定账号。学术滚雪球：从种子沿相关推荐扩，过门禁才写入 corpus.db。按视频号：只处理你粘贴的 BV，不扩散、不过门禁。中断后都用「续跑选中任务」，不要另开新任务号。

稳健采集（反爬应对）

  • WBI 签名 + buvid3 + bili_ticket
  • 真实浏览器 UA / Referer，关闭系统代理干扰
  • 请求间隔随机抖动；遇到 -412 / -352 指数退避
  • 单账号串行，失败单项记错继续下一个
  • 默认不要把间隔调到 0.2 秒以下

可选增强

pip install faster-whisper rapidocr onnxruntime
# 系统安装 ffmpeg 后才能把 DASH 音视频合成 mp4

未安装时程序仍可运行：字幕走官方接口，图片会下载但不 OCR，视频保留分离分片或仅链接。

使用边界

只采集你有权查看的公开内容，控制频率，不要用于骚扰或商业转售。Cookie 等同账号，只保存在本机 data/settings.json。视频版权归 UP 主与平台，本地缓存仅供个人研究与转写。

快速开始

选择一个工作方案

点一下会填好下面的媒体、转写和空间选项；仍可逐项改。

三个方案决定「要什么档案」。Whisper 和 OCR 跑在哪台机器，是完整归档 / 文字研究里的下一步，不是第四种方案。

目标账号与时间

打开 UP 主页，地址栏形如 https://space.bilibili.com/208259，数字就是 UID。可直接整段粘贴链接。一次多个就换行。

步骤 2

采集模块

要接着上次没跑完的账号，不要在这里重开。用本页底部的「续跑选中任务」。

步骤 3

媒体处理

页面链接是长期入口；播放直链会过期，因此不会当成永久成果保存。

步骤 4

转写完成后如何处理媒体

视频和图片只为转写/OCR 服务。文字落盘后，大文件可以删掉、压小，或先传到 Google Drive。

步骤 5

语音转文字

转写成果 transcript.mdtranscript.jsonSRTWebVTT

步骤 6

Whisper / OCR 跑在哪

完整归档和文字研究共用这一步。本机 Intel Mac 会很慢；云端 GPU 要先在「设置」里测试连接成功。

确认任务

轻量采集

不下载媒体；尝试提取官方字幕；图片下载并在 OCR 可用时识别。

列出本机保存的「按 UP 主」任务。选中断或取消的那条再续跑。

学术滚雪球

从种子沿相关推荐扩样本

从你认为像研究对象的视频出发，顺着 B 站「相关推荐」一层层扩。只有同时通过分区、播放量、互动、标签的视频才会继续往外滚。

通过门禁的每一条，都会采两层语料，缺一不可：

  • 视频层：标题、分区、标签、播放/评论数，以及台词转写（官方字幕，没有就 Whisper）。写入 videos / transcripts。
  • 评论层：热评 + 楼中楼，保留父子指针。写入 comments。

分析时不要把台词和评论混在一张表里：台词用 v_transcript_corpus，评论用 v_comment_corpus。种子请用真正讨论就业/阶层的稿件，不要用搞笑切片。

步骤 1

种子

例：复制一条「打工人 / 学历 / 就业」讨论视频的浏览器地址，每行一个。若要从某 UP 最近投稿里取种子，请单独一行贴 https://space.bilibili.com/数字UID，不要只靠视频链接（链接里 spm_id_from=333 这类参数不是 UID）。

步骤 2

门禁（以后都可以改）

深度 2、节点 80 适合试跑。互动比 = 评论数 ÷ 播放量；评论 ≥ 150 或 互动比 ≥ 0.003 即过关。两项都填 0 则关掉这条门禁。

只保留这些分区名或 tid。例：知识,资讯。留空则只靠下面的黑名单。

分区名里出现这些词就剪枝。研究亚文化时务必保留，否则推荐流会滚进游戏和鬼畜。

逗号分隔。视频标签、标题或简介命中其中任一即可。研究「躺平」可改成：躺平,内卷,孔乙己,牛马,阶层。留空则关掉标签门禁。

再收窄标题/简介。一般留空，靠标签词即可。

步骤 3

采什么

视频元数据（标题、分区、标签、播放量）对通过门禁的节点总会写入。下面决定还要不要台词、评论、弹幕。

学术分析至少勾选前两项。关掉转写就只剩元数据，没法做视频话语分析。

步骤 4

视频怎么转成文字

默认：先拿官方字幕；没有字幕再下载音频跑 Whisper。转写写入 transcript.md，并进分析库的 transcripts 表。

确认任务

开始或续跑这一次滚雪球

请先在「设置」登录。连续风控 5 次会停在当前队列里；用下面的续跑接着同一任务号，不要再点「从头开始」。

续跑会沿用该任务已保存的门禁、深度和节点上限。

Google Drive（rclone）

          
用来干什么：Whisper / 完整归档会在本机留下很大的音频或 MP4。转写完成后，可以把原片传到 Google Drive，再删掉本地文件，硬盘不会被撑满。分析用的文字已经写进 SQLite / Markdown，不依赖这些大文件。

          
没装 rclone、或不想传网盘，就把任务里的「空间策略」改成「提取后删除」或「全部留在本机」，这里可以不填。

          

            
            
          

          
远程名必须和终端 rclone listremotes 里的名字一致（常见 gdrive 或 googledrive，注意带不带冒号以界面提示为准）。目录是网盘上的文件夹，例：BiliArchiver。配置步骤见 README。

        

        

          
AutoDL 云端 GPU

          
用来干什么：Intel Mac 上 Whisper 一条 30 分钟视频可能要十几分钟。学术滚雪球、按视频号采集，以及「文字研究 / 完整归档」如果要对没有官方字幕的视频做语音识别，可以把音频送到租来的 GPU（例如 AutoDL 3090），识别完文字再回本机。爬虫、评论、门禁仍然在这台电脑上跑，云端只负责转写和 OCR。

          
用不到 Whisper 就跳过。要用时：到 AutoDL 实例页复制 SSH 登录指令整行和同一页的登录密码，点「一键接入」，保持这个页面开着。通了以后，任务步骤里把算力改成「云端 GPU」。云端工作机固定用 large-v3，和设置里本机 Whisper 选 small 无关。镜像选带 PyTorch 的官方镜像，不要选空白 Ubuntu。控制台「驱动/CUDA」是这张卡所在机器的驱动上限：写 12.8 就选 CUDA 12.x 镜像；写 13.2 则 12 或 13 都行。一键接入时会对照驱动和镜像，并补装 Whisper 需要的 libcublas.so.12。

          
          
到 AutoDL 控制台 → 你的实例 → 复制「SSH 登录指令」整行。例：ssh -p 38491 root@connect.bjb1.seetacloud.com。端口因实例而异，不要填 22。

          
          
同一页上的「登录密码」，不是你的 AutoDL 账号密码。
